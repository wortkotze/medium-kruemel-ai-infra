🔌 Multi-Repo Integration: So registriert sich ein Agent am Gateway

Wenn ein Worker im Repository kruemel-ai-agents gestartet wird, meldet er sich mit einem simplen POST-Call am zentralen Agent Gateway (:1518) an. Das Gateway erkennt den Agenten sofort, zeigt ihn hier im Cockpit als Online an und leitet Chat-Nachrichten aus Open WebUI direkt per SSE an den Worker weiter.

# Python-Worker Startup Hook (in kruemel-ai-agents): import requests GATEWAY_URL = "http://localhost:1518/api/registry" # 1. Beim Start registrieren requests.post(f"{GATEWAY_URL}/register", json={ "id": "agent-researcher", "name": "Deep Research & Intelligence Agent", "role": "Researcher", "endpoint": "http://host.containers.internal:8004", # Lokaler Worker-Port "tools": ["searxng_mcp", "browserless_mcp", "qdrant_mcp"], "model": "local-general" }) # 2. Heartbeat alle 20 Sekunden requests.post(f"{GATEWAY_URL}/heartbeat", json={"id": "agent-researcher"})
